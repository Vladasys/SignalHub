# Обновлённые требования к brand_counts

Сервис `brand_counts.php` должен считать автомобили только из раздела «Наш автопарк» и только со статусом «В наличии».
Ниже зафиксированы правила, которые нужно внедрить и проверить при сборе данных по брендам и филиалам.

## Источники данных
- **Общий список:** `https://www.sauto.md/ru/cars` — раздел «Наш автопарк» для основного филиала.
- **Филиал 2 (только в наличии):** `https://www.sauto.md/ru/cars/12561` — тот же раздел, но с выборкой «В наличии».

## Фильтрация
1. Брать только карточки, принадлежащие разделу «Наш автопарк». Любые позиции из «Автоподзаказа» игнорируются.
2. Оставлять только автомобили со статусом **«В наличии»** (без «В пути», «Под заказ» и т.п.).

## Подсчёты
После фильтрации нужно сформировать три набора данных:
- **Общий**: количество машин по брендам из раздела «Наш автопарк» со статусом «В наличии» (все филиалы).
- **Основной филиал**: количество по брендам для `https://www.sauto.md/ru/cars` после фильтрации по разделу и статусу.
- **Второй филиал**: количество по брендам для `https://www.sauto.md/ru/cars/12561` после фильтрации по разделу и статусу.

## Проверка и выгрузка
- Убедитесь, что ни одна запись из «Автоподзаказа» не попадает в итог.
- В ответе `brand_counts.php` публикуйте только отфильтрованные подсчёты, например:

```json
{
  "total": {"Toyota": 4, "Skoda": 3, "VW": 2},
  "branch_main": {"Toyota": 3, "Skoda": 2},
  "branch_secondary": {"Toyota": 1, "Skoda": 1, "VW": 2}
}
```

Всю логику сбора и фильтрации нужно перепроверить и задеплоить, чтобы исключить автомобили из автоподзаказа и оставить только позиции «В наличии».
